# 🔴 Liverpool FC Auto News - Multi-Page & Scheduled Poster Web App

ระบบดึงข่าวและรูปภาพฟุตบอลต่างประเทศ นำมาเขียนใหม่ด้วย AI (Gemini Flash) เป็นภาษาไทยในสไตล์คอลัมนิสต์เก๋าจัดจ้าน พร้อมระบบจัดการ **หลายเพจ (Multi-Page)**, **เพิ่ม RSS Feeds อิสระประจำเพจ**, และ **ระบบตั้งเวลาโพสต์ล่วงหน้า (Scheduled Posting)** อัตโนมัติ

---

## 🚀 ฟังก์ชันหลักที่เพิ่มเข้ามาใหม่

### 1. 📄 ระบบจัดการหลายเพจ (Multi-Page Management)
- เพิ่ม, แก้ไข, ลบ เพจ Facebook ได้ไม่จำกัดจำนวน
- มีปุ่มทดสอบ Token ของแต่ละเพจได้ทันทีก่อนบันทึก
- สามารถสลับการทำงานระหว่างเพจได้จากเมนูด้านบนของหน้าเว็บ

### 2. 📡 เพิ่ม RSS Feeds อิสระสำหรับแต่ละเพจ (Custom Feeds per Page)
- แต่ละเพจสามารถกำหนดแหล่งข่าว RSS แยกจากกันได้อย่างอิสระ
- เปิด/ปิด การดึงข่าวจากแต่ละ Feed ได้ด้วยสวิตช์ Toggle
- เพิ่ม Feed URL ใหม่หรือลบฟีดที่ไม่ต้องการออกได้ตลอดเวลา

### 3. 📅 ระบบตั้งเวลาโพสต์อัตโนมัติ (Scheduled Posting Queue)
- กดปุ่ม **"📅 ตั้งเวลา"** ที่การ์ดข่าวใดก็ได้
- เลือกวันและเวลาที่ต้องการให้โพสต์ หรือเลือกปุ่มลัด (+15 นาที, +30 นาที, +1 ชั่วโมง, เย็นนี้ 18:00, พรุ่งนี้ 08:30)
- ระบบมี Background Worker ทำงานตลอดเวลา เมื่อถึงเวลาที่ตั้งไว้ บอทจะยิงโพสต์ขึ้น Facebook ให้เองโดยอัตโนมัติ
- ดูคิวการตั้งเวลา, ยกเลิก, หรือลบรายการได้จากแท็บ **"คิวตั้งเวลาโพสต์"**

## 📁 โครงสร้างโปรเจกต์
```
News/
├── web_app.py            # เซิร์ฟเวอร์ Web Application + Scheduler Worker
├── run_webapp.bat        # ตัวเปิดใช้งาน Web App ในคลิกเดียว
├── templates/
│   └── index.html        # หน้าจอ Web Dashboard (จัดการหลายเพจ, ฟีด, ตั้งเวลา)
├── database.py           # ฐานข้อมูล SQLite (pages, page_feeds, scheduled_posts, articles)
├── news_fetcher.py       # ดึงข่าวตามฟีดของแต่ละเพจ + ดาวน์โหลดรูป
├── ai_rewriter.py        # Gemini AI สำนวนเก๋า + Multi-model fallback (3.8/3.7/3.5)
├── fb_poster.py          # รองรับการโพสต์ข้ามเพจตาม page_id และ access_token
└── .env                  # การตั้งค่าพื้นฐาน
```
