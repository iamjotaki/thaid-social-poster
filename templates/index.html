ทำตามขั้นตอนง่ายๆ ทีละสเต็ป ใช้งานได้ 100%

1

วิธีหา Facebook Page ID (ใช้เวลา 30 วินาที)

Page ID คือเลขรหัสประจำตัวเพจของคุณ (เช่น 675881132277790)

วิธีที่ 1 (ดูจาก Facebook โดยตรง): ไปที่หน้าเพจของคุณ > แท็บ "เกี่ยวกับ" (About) > เลื่อนลงดูหัวข้อ "ความโปร่งใสของเพจ" (Page Transparency) จะมีระบุ ID เพจ นำตัวเลขนี้มากรอกได้เลย

วิธีที่ 2 (ค้นหาผ่านเว็บฟรี): ก๊อปลิงก์หน้าเพจของคุณไปวางที่ findmyfbid.in หรือ lookup-id.com แล้วกดค้นหา ระบบจะแสดงตัวเลข Page ID ทันที

2

วิธีขอ Page Access Token (ขึ้นต้นด้วย EAAB...)

เปิด Graph API Explorer
  1. เข้าเว็บ developers.facebook.com แล้วล็อกอินด้วยบัญชี Facebook ที่เป็นแอดมินเพจ
  2. กดเมนู My Apps > Create App > เลือกประเภท Other (หรือ Business) > ตั้งชื่อแอป (เช่น My Post Bot)
  3. คลิกเมนูด้านบน Tools > Graph API Explorer
  4. ทางขวามือ ในช่อง Facebook App ให้คลิกเลือกชื่อแอปที่คุณเพิ่งสร้าง
3

สิทธิ์ (Permissions) สำคัญ 7 ตัวที่ต้องติ๊กเลือกให้ครบ

ในช่อง Permissions ให้คลิก Add a Permission แล้วค้นหาเพื่อติ๊กเลือกให้ครบทั้ง 7 ตัวนี้ในรอบเดียว:

1. pages_show_list

มองเห็นรายชื่อเพจของคุณ

2. pages_read_engagement

อ่านการมีส่วนร่วมพื้นฐาน

3. pages_manage_posts

โพสต์ข้อความและการ์ดลงเพจ

4. publish_video

โพสต์คลิปสั้น / Facebook Reels

5. read_insights

ดูยอดคนดู Reach, ยอดวิวคลิป และสถิติเพจ

6. pages_read_user_content

ดึงคอมเมนต์ลูกเพจเข้ามาให้ AI ช่วยอ่าน

7. pages_manage_engagement

ให้บอท AI หรือแอดมินตอบกลับคอมเมนต์ได้

5. คลิกปุ่มสีฟ้า "Generate Access Token" > กดยืนยันตัวตน และ ติ๊กเลือกเพจที่ต้องการเชื่อมต่อ

6. ตรงช่อง User or Page ให้เปลี่ยนจาก User Token เป็น ชื่อเพจของคุณ

7. คุณจะได้รหัส EAAB... ในช่อง Access Token คัดลอกรหัสนี้มาใช้งานได้ทันที

4
